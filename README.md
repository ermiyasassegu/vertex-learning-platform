# vertex-learning-platform

A production-style AI-powered learning platform with intelligent content search built with Next.js, Sanity, Clerk, and PostHog.

## Vertex Design System

The platform includes a unified design system with:
- **Typography**: Playfair Display & Inter
- **Color Palette**: Primary orange (100–500), Neutral slate (50–900), and White
- **Component Primitives**: Buttons, Badges, Search Inputs, Selects, Status Indicators, Progress Bars, Cards, Navigation, Breadcrumbs, and Pagination.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the Vertex Design System showcase.
