# Implementation Prompt: Configure Sanity Image Remote Patterns

## Goal
Resolve the Next.js runtime error on the course detail page:
`Invalid src prop (https://cdn.sanity.io/...) on 'next/image', hostname "cdn.sanity.io" is not configured under images in your 'next.config.js'`
by adding `cdn.sanity.io` (and placeholder domain `picsum.photos`) to `images.remotePatterns` in `next.config.ts`.

---

## Skills Referenced
- `sanity-best-practices` (`.agents/skills/sanity-best-practices/SKILL.md`)
  - Image handling and Next.js Image configuration (`references/image.md`, `references/nextjs.md`)
- Next.js Configuration documentation (`next.config.ts`)
- `AGENTS.md` (Sections 2, 6, 12, 13)

---

## Code & Config Inspected
- `next.config.ts`: Currently only configures `images.unsplash.com` in `remotePatterns`.
- `components/course/course-cover-poster.tsx`: Uses `next/image` with URLs generated by `@sanity/image-url` builder pointing to `https://cdn.sanity.io/...`.
- `studio/scripts/seed/seed.ndjson`: Contains image assets on `cdn.sanity.io` and placeholder references on `picsum.photos`.

---

## Decisions & Assumptions
1. **Configure `remotePatterns` in `next.config.ts`**:
   - Add `cdn.sanity.io` with protocol `https` and optional pathname wildcard (`**`).
   - Add `picsum.photos` with protocol `https` to safely support any seed image assets.
   - Retain existing `images.unsplash.com`.

---

## Files to Touch / Create
- `next.config.ts`: Add `cdn.sanity.io` and `picsum.photos` to `images.remotePatterns`.

---

## Security Considerations
- Restricting `remotePatterns` strictly to HTTPS protocol and required hostnames (`cdn.sanity.io`, `images.unsplash.com`, `picsum.photos`).
